# Documentation and UX Portfolio

Our documentation and UX portfolio showcases selected examples of technical documentation, API documentation, developer documentation, and UX writing work delivered by Technically Write Ltd.

We support a wide range of documentation platforms and workflows, helping teams deliver clear, structured, and scalable content across complex software products.

Learn more about our [technical documentation services](/technical-documentation-services) or view our [technical documentation pricing](/technical-writing-pricing).

## Documentation portfolio

Below is a selection of documentation projects delivered in whole or in part by Technically Write Ltd. These examples reflect the range of platforms and publishing workflows we support across developer documentation, product documentation, and API reference.

:::note
Only a limited number of examples can be shared publicly. Much of our work is covered by client intellectual property restrictions and security requirements. We will always share what we can, but customer confidentiality is a priority.
:::

### Technically Write Ltd.
**Stack:** Docusaurus + plugins  

The Technically Write Ltd website, implemented as a modern documentation-style site using Docusaurus. Built to support structured content, scalable navigation, and a maintainable authoring workflow.

### Blackwall Documentation
**Stack:** MkDocs + plugins  

Documentation for Blackwall’s platform, covering core product concepts and practical guidance to help users deploy, configure, and operate the service effectively.

### R3 Documentation (Corda)
**Stack:** Hugo + plugins + tools  

Documentation for Corda, an enterprise distributed ledger platform, covering platform concepts, operations, developer guidance, and reference material.

### Trilio (for Kubernetes)
**Stack:** GitBook  

Documentation contributions for Trilio’s Kubernetes-focused data protection and backup solution.

### WhiteHat Security / Black Duck — Continuous Dynamic Docs
**Stack:** Antora + tools  

Product documentation for the Continuous Dynamic platform, supporting dynamic application security testing.

### WhiteHat Security / Black Duck — API Documentation
**Stack:** ReadMe (readme.io)  

API reference and developer guidance for the Continuous Dynamic API suite.
